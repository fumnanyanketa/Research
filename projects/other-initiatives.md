## 2. AI agent agency

**What:** Build agents/automations for SMEs — lead gen, bookings, bookkeeping, content. Educate → demonstrate → sell. Build fee + €300–500/month maintenance.
**Status:** Idea stage; founder building skills; ~2 days per agent once scoped; first niche thinking done (barbershops/salons worked through end-to-end in the meeting).
**Case study:** the association itself — questionnaire to map bottlenecks, then automations + website overhaul; September employment event as the live demo.
**Watch-outs (from the meeting):** Finnish SMEs need education before they buy; check residence-permit implications before going full-time (income thresholds; startup-entrepreneur permit); invoice through own company; sort union/YEL/insurance.
**Next step:** Send the association questionnaire; founder asks current employer about extra work via own company.

## 3. AI photography tool

**What:** Two-product vision: (A) auto-cull + auto-edit trained on the photographer's own style — 200 client-ready images same-day; (B) AI-operated multi-camera rigs (2–4 bodies, different lenses, tracking/zooming autonomously) supervised remotely — one photographer, many gigs.
**Go-to-market:** subscription €15–30/month with tiers; enter as a plugin to existing editors (Lightroom) before any proprietary hardware; camera-brand partnerships (Sony/Canon) once proven.
**Tech direction discussed:** agent = LLM + tools in a loop; fine-tune a small open-source model on images; custom GPT + actions as a quick prototype.
**Next step:** Call with the technical partner to choose the architecture and define an MVP (likely product A, editing-only, single style profile). Report back to the group.

## 4. English Parliament — "Community 2027"

**What:** Train immigrants/minorities (one representative chosen per community) for 4–5 months — debate, public speaking, how Finnish democracy works — culminating in a Parliament-simulation event near the 2027 parliamentary elections. Possibly a documentary. Shows society what diverse representation looks like; equips participants for municipal politics regardless.
**Status:** Early draft concept doc exists; name "Community 2027"; seeking the AI/tech component (AI-assisted debate training? speech feedback? civic-info assistant?) and funding from foundations that back bold ideas (Ford Foundation mentioned as the archetype).
**Timing pressure:** election is spring 2027 and training takes 4–5 months → program must start late 2026 / very early 2027 → funding application this autumn.
**Next step:** Share the draft doc; brainstorm the AI component; shortlist 3 foundations and their deadlines.

**Next step:** One-pager defining purpose (publish or not), format, and consent approach before announcing.

## 6. Finnish language app

**What:** Member's language-learning app; word gate built from the top 10,000 real Finnish words to block AI-hallucinated vocabulary.
**Decisions leaning:** standard kirjakieli for beginners; puhekieli/slang ("Helsinki poetry") as a later level — immigrants first need to understand natives, not perform slang. Prototyped on Lovable; Vercel is the production-grade target.
**Next step:** Migrate prototype toward production hosting; define the slang-level roadmap separately.
