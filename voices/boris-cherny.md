# Boris Cherny

> Creator and Head of Claude Code at Anthropic, the fastest-growing AI coding tool, who argues coding is "effectively solved" for the work he does.

Window: 2026-04-11 → 2026-06-11 · Compiled: 2026-06-11

## Interviews & podcast appearances

### ~Late April / early May 2026 (date unconfirmed; reports cite both April 20 and May 4) — Sequoia AI Ascent 2026: "Why Coding Is Solved, and What Comes Next" (fireside with Lauren Reeder)
- Link: https://www.youtube.com/watch?v=SlGRN8jh2RI (see also https://jinlow.medium.com/from-ide-to-agent-console-what-boris-chernys-ai-ascent-interview-is-really-telling-us-about-the-9edab4c7742f ; https://finance.biggo.com/news/bd63c89c5a3716f3)
- Key ideas:
  - He hasn't written a line of code by hand since October 2025 and hasn't written any code in 2026; for the code he writes, coding is "effectively solved."
  - His primary interface is now his phone (Claude app code tab), running 5–10 active sessions that spawn "a few hundred agents," with "a few thousand" agents running overnight; personal record of 150 PRs in a single day.
  - Claude Code was deliberately built for a model that didn't yet exist — a "product overhang" strategy that meant ~6 months of unusable performance before Opus 4 triggered exponential adoption.
  - The developer-tools power shift: from IDE to "agent console" — the engineer's job becomes directing and reviewing agent fleets rather than typing code.

### ~Late May 2026 (date unconfirmed) — Platformer podcast (ep. 3, Casey Newton): "Claude Code's creator on the end of the software engineer"
- Link: https://www.platformer.news/boris-cherny-interview-ai-jobs/ (video: https://www.youtube.com/watch?v=PZ9u6DR8qOU)
- Key ideas:
  - The title "software engineer" could start to disappear as soon as the end of this year, dissolving into something closer to "builder," as designers, PMs, and managers around him start shipping code.
  - Major job loss from automation "really is coming — but job creation is, too."
  - Companies will paradoxically need both far fewer engineers and far more of them; he discusses what he tells new CS grads about where to build a career.
  - The surprise upending his predictions: the people getting the most out of AI tools are increasingly electricians, doctors, and carpenters rather than professional engineers.

### 2026-06-08 — Fortune Brainstorm Tech (Aspen), opening session
- Link: https://fortune.com/2026/06/08/anthropics-boris-cherny-creator-of-claude-code-says-there-are-days-he-manages-tens-of-thousands-of-ai-agents-at-once/ (follow-ups: https://fortune.com/2026/06/09/boris-cherny-claude-code-says-comparing-ai-costs-to-wrong-thing-anthropic/ ; https://fortune.com/2026/06/11/anthropic-claude-boris-cherny-doesnt-write-code-by-hand-anymore/)
- Key ideas:
  - He was managing "maybe a few hundred agents" that morning; "Some days it's … thousands, or tens of thousands."
  - Claude Code now uses subagents that are other Claudes — and another Claude does the prompting rather than the user ("I now just write loops to prompt Claude Code": https://officechai.com/ai/i-now-just-write-loops-to-prompt-claude-code-claude-code-creator-boris-cherny/ ).
  - Anthropic's internal code review: a team of Claude instances with distinct personas collaboratively reviews PRs, catching "pretty much every bug" — token-expensive but thorough; a human still approves.
  - On enterprise sticker shock: stop comparing Claude Code to a $20/month coding assistant — compare it to the cost of the work it replaces.
  - He hasn't handwritten a line of code in 8 months; Claude Code is generating an annualized revenue run rate exceeding $2.5 billion.

## Core theses right now

- Coding is "effectively solved" for the kind of work he does; he has written zero lines of code by hand in ~8 months and works by orchestrating agents from his phone.
- The unit of engineering work is shifting from writing code to managing fleets of agents — hundreds to tens of thousands at a time, with Claudes prompting and reviewing other Claudes.
- The "software engineer" job title may begin dissolving into "builder" as early as the end of 2026, with non-engineers shipping production code.
- AI-driven job loss is real and coming, but so is job creation; the biggest beneficiaries are increasingly non-programmers (electricians, doctors, carpenters).
- Token spend should be judged against the cost of the human work replaced, not against $20/month assistant subscriptions; heavy token use (e.g., multi-persona code review) is worth it.
